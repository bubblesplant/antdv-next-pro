组件/表格增强

表格增强 ​

DragSortTable、RowEditorTable、CellEditorTable 复用 ProTable 的 schema、数据请求、原生配置与语义样式，分别提供拖拽排序、整行编辑、单元格编辑。

vue
<script setup lang="ts">
import { ref } from 'vue'
import { Button, Space } from 'antdv-next'
import {
  CellEditorTable,
  DragSortTable,
  RowEditorTable,
  type EditableConfig,
  type ProColumns,
  type ProKey,
  type ProTableInstance,
} from '@bubblesjs/antdv-next-pro'

interface Task extends Record<string, unknown> {
  id: number
  name: string
  priority: number
}
const initial: Task[] = [
  { id: 1, name: '编写示例', priority: 1 },
  { id: 2, name: '交互验收', priority: 2 },
  { id: 3, name: '整理文档', priority: 3 },
]
const columns: ProColumns<Task>[] = [
  {
    title: '任务',
    dataIndex: 'name',
    formItemProps: { rules: [{ required: true, message: '请输入任务名称' }] },
  },
  { title: '优先级', dataIndex: 'priority', valueType: 'digit', fieldProps: { min: 1, max: 5 } },
]
const dragRows = ref(initial.map((row) => ({ ...row })))
const rowRows = ref(initial.map((row) => ({ ...row })))
const cellRows = ref(initial.map((row) => ({ ...row })))
const rowAction = ref<ProTableInstance<Task>>()
const cellAction = ref<ProTableInstance<Task>>()
const feedback = ref('拖动手柄排序；也可以聚焦手柄后按上下方向键。')
const editable: EditableConfig<Task> = {
  type: 'single',
  onSave: async (_key, record) => {
    feedback.value = `已保存任务：${record.name}`
    return true
  },
}
function dragEnd(from: number, to: number, rows: Task[]) {
  feedback.value = `第 ${from + 1} 项移至第 ${to + 1} 项；当前顺序：${rows.map((row) => row.name).join('、')}`
}
function begin(_key: ProKey, record: Task) {
  feedback.value = `正在编辑：${record.name}`
}
function end(_key: ProKey, record: Task) {
  feedback.value = `编辑结束：${record.name}`
}
</script>

<template>
  <div class="enhanced-demo" data-demo="table-enhancements">
    <section data-demo-drag-table>
      <h3>拖动排序</h3>
      <p>拖动行首手柄，或聚焦手柄后按 ↑ / ↓。排序结果保存在当前页面。</p>
      <DragSortTable
        v-model:data-source="dragRows"
        row-key="id"
        :columns="columns"
        :search="false"
        :options="false"
        :pagination="false"
        :tool-bar-render="false"
        @drag-sort-end="dragEnd"
      />
    </section>
    <section data-demo-row-table>
      <h3>行编辑</h3>
      <p>双击一行进入编辑，焦点离开当前行后保存；按钮也可启动、保存和取消。</p>
      <Space class="actions">
        <Button data-demo-row-start @click="rowAction?.startEditable(1)">编辑第一行</Button>
        <Button data-demo-row-save @click="rowAction?.saveEditable(1)">保存第一行</Button>
        <Button data-demo-row-cancel @click="rowAction?.cancelEditable(1)">取消编辑</Button>
      </Space>
      <RowEditorTable
        ref="rowAction"
        v-model:data-source="rowRows"
        row-key="id"
        :columns="columns"
        :editable="editable"
        :search="false"
        :options="false"
        :pagination="false"
        :tool-bar-render="false"
        :on-row-edit-start="begin"
        :on-row-edit-end="end"
      />
    </section>
    <section data-demo-cell-table>
      <h3>单元格编辑</h3>
      <p>双击名称或优先级，只编辑当前单元格；切换单元格时先保存并校验。</p>
      <Space class="actions">
        <Button data-demo-cell-start @click="cellAction?.startEditable(1)">编辑首个单元格</Button>
        <Button data-demo-cell-save @click="cellAction?.saveEditable(1)">保存第一行</Button>
        <Button data-demo-cell-cancel @click="cellAction?.cancelEditable(1)">取消编辑</Button>
      </Space>
      <CellEditorTable
        ref="cellAction"
        v-model:data-source="cellRows"
        row-key="id"
        :columns="columns"
        :editable="editable"
        :search="false"
        :options="false"
        :pagination="false"
        :tool-bar-render="false"
        :on-row-edit-start="begin"
        :on-row-edit-end="end"
      />
    </section>
    <p data-demo-enhanced-state aria-live="polite">{{ feedback }}</p>
  </div>
</template>

<style scoped>

}

}

最小用法 ​

vue
<script setup lang="ts">
import { ref } from 'vue'
import { DragSortTable, type ProColumns } from '@bubblesjs/antdv-next-pro'

type Task = { id: number; title: string }
const rows = ref<Task[]>([
  { id: 1, title: '整理需求' },
  { id: 2, title: '验证实现' },
])
const columns: ProColumns<Task>[] = [{ title: '任务', dataIndex: 'title' }]
</script>

<template>
  <DragSortTable
    v-model:dataSource="rows"
    row-key="id"
    :columns="columns"
    :search="false"
    :pagination="false"
  />
</template>

DragSortTable ​

复用 ProTable 的记录类型 T 与请求参数类型 P。手柄支持拖拽和键盘上下方向键；受控模式由父组件接收新数组后完成重排。

属性 ​

属性类型默认值说明与来源
dragSortKeystring__dragSort排序列 key 或 dataIndex；列不存在时在最前插入手柄列。
dragSortHandlerRender(record: T, index: number) => VNodeChild默认拖拽图标自定义手柄内部内容，拖拽与键盘行为仍由外层手柄提供。
onDragSortEnd(beforeIndex: number, afterIndex: number, rows: T[]) => void | Promise<void>—排序完成回调；与 drag-sort-end 为同一监听通道。
onDataSourceChange(rows: T[]) => void—顺序变化通知；与 data-source-change 为同一监听通道。
dataSourceT[]—受控数据，使用 v-model:data-source 接收重新排序后的完整数组。
defaultDataSourceT[][]非受控初始数据。
其余属性ProTableProps<T, P>ProTable 默认值全部继承 ProTable 属性表 与列属性，原生透传项见 Table API。

事件 ​

事件 / 回调参数说明与来源
update:data-sourcerows: T[]重排数据双向绑定更新。
drag-sort-endbeforeIndex: number, afterIndex: number, rows: T[]对应 onDragSortEnd，索引为当前完整数据源的位置。
data-source-changerows: T[]对应 onDataSourceChange，重排后的完整数据。
其他 ProTable 事件保持参数转发 ProTable 事件。

事件索引是当前数据源位置，分页后不可视为数据库永久排序编号。异步持久化在业务回调中处理，返回 Promise 不会自动回滚。默认手柄类名 ant-pro-table-drag-icon 随全局或组件前缀变化。

RowEditorTable ​

双击行进入编辑，焦点离开该行 150ms 后校验并保存；行内移动焦点不保存。editable.onSave 返回 false 或校验失败时保留编辑。

属性 ​

属性类型默认值说明与来源
dataSourceT[]—value 的别名，支持 v-model:data-source；value 同时存在时优先。
defaultDataSourceT[][]defaultValue 的别名；defaultValue 优先。
onRowEditStart(key: ProKey, record: T) => void—进入编辑通知，可用 @row-edit-start 监听。
onRowEditEnd(key: ProKey, record: T) => void—成功保存、取消或移除编辑 key 后通知，可用 @row-edit-end。
editablefalse | EditableConfig<T>{ type: 'single' }全部配置见 editable，包括 onSave/onCancel/formProps/formRef。
recordCreatorPropsfalse | RecordCreatorProps<T>false默认隐藏创建按钮，可显式开启，见创建行配置。
onRowTableProps<T>['onRow']—原生 Table 行绑定；原回调先执行，可 preventDefault 阻止自动激活。
其余属性EditableProTableProps<T, P>继承全部 EditableProTable 属性 继续有效，包括 value/defaultValue/editableKeys/maxLength/formItemProps；search/pagination 固定关闭。

事件与回调 ​

事件 / 回调参数说明与来源
update:data-sourcerows: T[]表格值变化，支持数据别名双向绑定。
update:editable-keyskeys: ProKey[]编辑 key 回传。
row-edit-start / onRowEditStartkey: ProKey, record: T自动或实例方法进入编辑。
row-edit-end / onRowEditEndkey: ProKey, record: T成功保存、取消或编辑 key 移除。
其他 EditableProTable 事件保持参数见 EditableProTable 事件表。

onRowEditStart 与 @row-edit-start（以及 end 对应写法）各是同一条 Vue 监听，任选一种。

CellEditorTable ​

双击可编辑单元格，只将当前单元格切换为输入；焦点离开单元格 150ms 后保存。切换单元格前先保存当前项，校验失败会阻止切换。

属性 ​

属性类型默认值说明与来源
全部属性CellEditorTableProps<T, P> = RowEditorTableProps<T, P>继承 RowEditorTable没有新增属性；逐项见 RowEditorTable 属性 和 EditableProTable 属性。
columns[].onCellTableColumnType<T>['onCell']—原生 Column 绑定，原双击回调先执行，可 preventDefault 阻止激活。

事件与回调 ​

事件 / 回调参数说明与来源
update:data-sourcerows: T[]表格值变化，支持数据别名双向绑定。
update:editable-keyskeys: ProKey[]编辑 key 回传。
row-edit-start / onRowEditStartkey: ProKey, record: T自动或实例方法进入编辑。
row-edit-end / onRowEditEndkey: ProKey, record: T成功保存、取消或编辑 key 移除。
其他 EditableProTable 事件保持参数见 EditableProTable 事件表。

readonly、editable=false 或 valueType="option" 的列不可编辑。实例 startEditable(key) 选择该行第一个允许编辑的字段。

插槽 ​

组件插槽与参数来源
DragSortTable全部透传 ProTable 插槽表，包括 toolbar-actions、动态表头/单元格、before-table/after-table 和原生 Table 插槽；没有新增插槽。
RowEditorTable / CellEditorTable全部透传 EditableProTable 插槽表，包括 creator-button 和所有 ProTable 插槽；没有新增插槽。

组件实例 ​

组件 / 方法返回值行为与来源
DragSortTableProTableInstance<T>完整继承 ProTable 实例方法表，没有新增方法。
RowEditorTable / CellEditorTableProTableInstance<T>完整方法及参数见 ProTable 实例表，以下三项协调编辑通知。
startEditable(key: ProKey)boolean进入整行/首个可编辑单元格并通知 onRowEditStart。
saveEditable(key: ProKey)Promise<boolean>校验保存；成功时通知 onRowEditEnd，失败保留编辑。
cancelEditable(key: ProKey)void取消恢复并通知 onRowEditEnd。

配置与样式 ​

prefixCls/classes/styles 与原生主题均继承 ProTable；扩展 token、语言和 RTL 见 ProConfigProvider。列 render、formItemRender、fieldProps、formItemProps 的完整签名和原生属性链接见 ProColumns。

自动保存的 150ms 为焦点缓冲时间。网络保存应在 editable.onSave 中返回实际 Promise；跨页排序和服务端排名由业务维护。
