组件/ProConfigProvider

ProConfigProvider ​

Pro 组件可独立继承最近的 Antdv Next ConfigProvider，包括语言、主题算法、全局 token、原生组件 token、前缀、RTL、尺寸、禁用与弹层容器。ProConfigProvider 增加 Pro 文案、自定义字段类型和 Pro token 的局部覆盖。

vue
<script setup lang="ts">
import { ConfigProvider, Switch, theme } from 'antdv-next'
import enUS from 'antdv-next/locale/en_US'
import zhCN from 'antdv-next/locale/zh_CN'
import { computed, ref } from 'vue'
import {
  ProCard,
  ProConfigProvider,
  ProField,
  ProForm,
  ProFormText,
} from '@bubblesjs/antdv-next-pro'

const english = ref(false)
const dark = ref(false)
const accent = ref(false)
const nativeTheme = computed(() => ({
  algorithm: [theme.compactAlgorithm, dark.value ? theme.darkAlgorithm : theme.defaultAlgorithm],
  token: { colorPrimary: accent.value ? '#722ed1' : '#1677ff' },
  components: { Card: { headerFontSize: 20 } },
}))
</script>

<template>
  <div style="display: flex; gap: 16px; margin-block-end: 16px; flex-wrap: wrap">
    <label>English <Switch v-model:checked="english" /></label>
    <label>Dark <Switch v-model:checked="dark" /></label>
    <label>Purple <Switch v-model:checked="accent" /></label>
  </div>
  <ConfigProvider :locale="english ? enUS : zhCN" :theme="nativeTheme" prefix-cls="demo">
    <ProConfigProvider :token="{ colorTextSecondary: '#9254de' }">
      <ProCard title="ConfigProvider → ProConfigProvider">
        <p><ProField value-type="switch" :text="true" /></p>
        <ProForm>
          <ProFormText name="title" :label="english ? 'Title' : '标题'" />
        </ProForm>
      </ProCard>
    </ProConfigProvider>
  </ConfigProvider>
</template>

配置入口 ​

定制对象入口示例
全局主题与算法ConfigProvider.themetoken.colorPrimary、darkAlgorithm、compactAlgorithm
原生组件 tokenConfigProvider.theme.componentsCard.headerFontSize、Result.iconFontSize
Pro 自绘区域的主题ProConfigProvider.tokencolorText、colorTextSecondary、colorBgContainer
Pro 文案ProConfigProvider.intlcreateIntl('custom', messages)
扩展 valueTypeProConfigProvider.valueTypeMaprender / formItemRender

theme.components.Result 作用于原生 Result。ProTable、ProCard 的扩展 token 通过 ProConfigProvider.token 配置；原生 components 中没有新增同名 Pro 组件键。

Props ​

属性类型 / 默认值说明
tokenProToken基于原生解析 token 的局部覆盖，嵌套 Provider 合并显式覆盖
intlIntlType当前显式值 → 祖先显式值 → 最近原生 locale → 中文
valueTypeMapProValueTypeMap按类型名继承；同名类型的整个定义替换，其他类型继续继承
prefixClsstringPro 命名空间；默认 ant-pro，原生 prefix 为 demo 时为 demo-pro
darkboolean / 未指定true 追加深色算法，保留 compact；未指定继承原生配置
hashedboolean / 未指定继承或覆盖原生 hash 类配置
contentHashstring当前请求缓存键的内容版本
autoClearCacheboolean / false卸载仅清理当前 Provider 拥有的缓存
needDepsboolean / false无覆盖配置时复用父 Provider 的缓存作用域

ProProvider 是 Vue Provider 组件别名。useProConfig() / useIntl() / useProPrefix() 返回响应式上下文；在 setup 中读取其 ref，渲染时使用 .value。

国际化 ​

内置 34 个基线语言包，intlMap、intlMapKeys 以及 enUSIntl、zhCNIntl 等均可导入。原生 locale.locale 支持大小写、下划线、连字符和语言前缀匹配。缺失消息依次回退中文与调用方默认文案，显式空字符串保留。

ts
import { createIntl } from '@bubblesjs/antdv-next-pro'

const intl = createIntl('en-US', {
  tableForm: { search: 'Find', reset: 'Clear' },
})

查询、编辑、表单操作、字段布尔值、验证码和上传等 Pro 自有文案读取统一 intl；日期面板、分页、原生校验信息读取 Antdv Next 的语言包。新增上传提示在中英文包中提供翻译，其余基线语言未新增的消息按上述规则回退。

token 的实际消费范围 ​

以下为当前已有渲染消费者的 Pro token；原生组件另行消费自身 theme.components token。类型继承 GlobalToken 不表示每个原生 token 都有对应的 Pro 自绘部位。

token实际生效部位
colorTextField 根、Table、表单、List、FieldLabel、DropdownFooter
colorTextSecondaryCard 副标题/提示、Table 次要文本、LabelIconTip
colorPrimaryCard 选中轮廓、Table 列设置选中项
colorPrimaryBgTable 选择/提示区
colorBgContainerTable 全屏、List 背景
colorBgElevatedTable 列设置弹层、DropdownFooter
colorFillAlterTable 列设置拖拽项悬停、SchemaForm 列表
colorBorderSecondaryCard/List 分隔、DropdownFooter、Table 提示区
colorErrorTable 编辑错误提示
boxShadowSecondaryFilterDropdown 弹层
paddingLGForm Group 间距、QueryFilter 列、Steps 内容、List 行、ListToolBar、FilterDropdown
borderRadiusLGTable 弹层/提示区
marginField option 操作间距
boxShadow启用 boxShadow 的 Card
padding / paddingXSCard 普通/小号标题的回退内边距，显式原生 Card headerPadding 配置优先

具体组件样式可再通过 classes / styles 覆盖。

token.layout.header/sider/pageContainer 保留类型和嵌套合并协议。本轮未建设 ProLayout/PageContainer，因此这些布局字段没有对应可渲染组件，不能据类型接受推断页面外观已改变。
