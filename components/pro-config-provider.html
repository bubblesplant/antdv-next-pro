组件/ProConfigProvider

ProConfigProvider ​

Pro 组件可独立继承最近的 Antdv Next ConfigProvider，包括语言、主题算法、全局 token、原生组件 token、前缀、RTL、尺寸、禁用与弹层容器。ProConfigProvider 增加 Pro 文案、自定义字段类型和 Pro token 的局部覆盖。

vue
<script setup lang="ts">
import { ConfigProvider, Switch, theme } from 'antdv-next'
import enUS from 'antdv-next/locale/en_US'
import zhCN from 'antdv-next/locale/zh_CN'
import { computed, ref } from 'vue'
import {
  ProCard,
  ProConfigProvider,
  ProField,
  ProForm,
  ProFormText,
} from '@bubblesjs/antdv-next-pro'

const english = ref(false)
const dark = ref(false)
const accent = ref(false)
const nativeTheme = computed(() => ({
  algorithm: [theme.compactAlgorithm, dark.value ? theme.darkAlgorithm : theme.defaultAlgorithm],
  token: { colorPrimary: accent.value ? '#722ed1' : '#1677ff' },
  components: { Card: { headerFontSize: 20 } },
}))
</script>

<template>
  <div style="display: flex; gap: 16px; margin-block-end: 16px; flex-wrap: wrap">
    <label>English <Switch v-model:checked="english" /></label>
    <label>Dark <Switch v-model:checked="dark" /></label>
    <label>Purple <Switch v-model:checked="accent" /></label>
  </div>
  <ConfigProvider :locale="english ? enUS : zhCN" :theme="nativeTheme" prefix-cls="demo">
    <ProConfigProvider :token="{ colorTextSecondary: '#9254de' }">
      <ProCard title="ConfigProvider → ProConfigProvider">
        <p><ProField value-type="switch" :text="true" /></p>
        <ProForm>
          <ProFormText name="title" :label="english ? 'Title' : '标题'" />
        </ProForm>
      </ProCard>
    </ProConfigProvider>
  </ConfigProvider>
</template>

属性 ​

属性类型默认值说明 / 来源
intlIntlType—Pro 语言；当前显式值 → 祖先显式值 → 最近原生 locale → 中文。
tokenProToken{}在原生 token 上局部覆盖；祖先与当前覆盖合并，见配置结构。
valueTypeMapProValueTypeMap{}按类型名继承，同名定义整体替换；定义见下表。
prefixClsstringant-proPro 命名空间；原生 prefix 为 demo 时默认 demo-pro。
darkbooleanundefinedtrue 追加深色算法且保留已有算法；false 保留原生算法，不强制浅色。
hashedbooleanundefined继承或覆盖原生 theme.hashed。
contentHashstring—请求缓存键的内容版本，省略继承祖先。
autoClearCachebooleanfalse卸载仅清理当前 Provider 自有缓存。
needDepsbooleanfalse有祖先且无 intl/token/valueTypeMap/prefixCls/dark/hashed 覆盖时复用父缓存。

ProProvider 是同一组件的别名。本组件不透传任意原生 ConfigProvider 属性：locale、theme、direction、componentSize、componentDisabled、getPopupContainer 等应在外层 Antdv Next ConfigProvider 设置。

国际化 ​

内置 34 个基线语言包，intlMap、intlMapKeys 以及 enUSIntl、zhCNIntl 等均可导入。原生 locale.locale 支持大小写、下划线、连字符和语言前缀匹配。缺失消息依次回退中文与调用方默认文案，显式空字符串保留。

ts
import { createIntl } from '@bubblesjs/antdv-next-pro'

const intl = createIntl('en-US', {
  tableForm: { search: 'Find', reset: 'Clear' },
})

查询、编辑、表单操作、字段布尔值、验证码和上传等 Pro 自有文案读取统一 intl；日期面板、分页、原生校验信息读取 Antdv Next 的语言包。新增上传提示在中英文包中提供翻译，其余基线语言未新增的消息按上述规则回退。

colorPrimaryBgTable 选择/提示区

colorBgElevatedTable 列设置弹层、DropdownFooter
colorFillAlterTable 列设置拖拽项悬停
colorBorderSecondaryTable 提示区
colorSplit / lineWidth / lineTypeCard/List 分隔线；DropdownFooter 使用 colorSplit

Card 标题左右间距优先使用显式原生 headerPadding/headerPaddingSM；未配置时使用 Pro 的 padding/paddingXS。这两个原生 Card 配置不控制标题上下间距。FilterDropdown 内容 padding 默认固定为 16px，可用组件属性覆盖。

具体组件样式可再通过 classes / styles 覆盖。

token.layout.header/sider/pageContainer 保留类型和嵌套合并协议。本库未提供 ProLayout/PageContainer 渲染组件，因此这些布局字段当前不会改变页面外观。
