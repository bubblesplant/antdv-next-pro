组件/ProDescriptions

ProDescriptions ​

使用与表格相同的字段 schema 展示单条记录，支持请求、格式化与逐字段编辑。排版属性沿用 antdv-next 的 Descriptions。

vue
<script setup lang="ts">
import { ref } from 'vue'
import { Button, Space } from 'antdv-next'
import {
  ProDescriptions,
  type ProDescriptionsColumn,
  type ProDescriptionsInstance,
  type ProKey,
} from '@bubblesjs/antdv-next-pro'

interface ProjectDetails extends Record<string, unknown> {
  name: string
  owner: string
  status: string
  budget: number
  createdAt: string
  notes: string
}

const action = ref<ProDescriptionsInstance<ProjectDetails>>()
const server = ref<ProjectDetails>({
  name: '组件升级计划',
  owner: '林晓',
  status: 'active',
  budget: 16800,
  createdAt: '2026-10-21',
  notes: '先完成示例，再安排团队验收。',
})
const requests = ref(0)
const feedback = ref('点击字段旁的编辑图标；清空项目名称后保存可查看校验。')
const columns: ProDescriptionsColumn<ProjectDetails>[] = [
  {
    title: '项目名称',
    dataIndex: 'name',
    formItemProps: { rules: [{ required: true, message: '请输入项目名称' }] },
  },
  { title: '负责人', dataIndex: 'owner' },
  {
    title: '状态',
    dataIndex: 'status',
    valueType: 'select',
    valueEnum: {
      active: { text: '进行中', status: 'Processing' },
      done: { text: '已完成', status: 'Success' },
      pending: { text: '待开始', status: 'Default' },
    },
  },
  { title: '预算', dataIndex: 'budget', valueType: 'money', editable: false },
  { title: '创建日期', dataIndex: 'createdAt', valueType: 'date', editable: false },
  { title: '备注', dataIndex: 'notes', valueType: 'textarea' },
]

async function request() {
  requests.value++
  return { data: { ...server.value }, success: true }
}
async function save(_key: ProKey, record: ProjectDetails) {
  server.value = { ...record }
  feedback.value = `已保存：${record.name} · ${record.owner}`
  return true
}
</script>

<template>
  <div class="descriptions-demo" data-demo="pro-descriptions">
    <ProDescriptions
      ref="action"
      title="项目详情"
      tooltip="通过 request 获取详情，逐字段编辑并保存。"
      :columns="columns"
      :request="request"
      :editable="{ type: 'single', onSave: save }"
      :column="{ xs: 1, sm: 2 }"
      bordered
      @editable-error="feedback = '请检查字段内容后重试。'"
    >
      <template #extra>
        <Space>
          <Button data-demo-descriptions-edit @click="action?.startEditable('name')"
            >编辑名称</Button
          >
          <Button data-demo-descriptions-reload @click="action?.reload()">重新加载</Button>
        </Space>
      </template>
    </ProDescriptions>
    <p data-demo-descriptions-state aria-live="polite">已加载 {{ requests }} 次。{{ feedback }}</p>
    <pre data-demo-descriptions-data>{{ JSON.stringify(server, null, 2) }}</pre>
  </div>
</template>

<style scoped>
.descriptions-demo {
  display: grid;
  gap: 16px;
}
p {
  margin: 0;
}
pre {
  margin: 0;
  overflow: auto;
  padding: 16px;
  border: 1px solid #d9d9d9;
  border-radius: 8px;
}
</style>

最小用法 ​

vue
<script setup lang="ts">
import { ref } from 'vue'
import { ProDescriptions, type ProDescriptionsColumn } from '@bubblesjs/antdv-next-pro'

type Profile = { name: string; status: string }
const profile = ref<Profile>({ name: '张三', status: 'active' })
const columns: ProDescriptionsColumn<Profile>[] = [
  { title: '姓名', dataIndex: 'name', formItemProps: { rules: [{ required: true }] } },
  {
    title: '状态',
    dataIndex: 'status',
    valueType: 'select',
    valueEnum: { active: '启用', inactive: '停用' },
  },
]
</script>

<template>
  <ProDescriptions
    title="用户信息"
    :columns="columns"
    :data-source="profile"
    :editable="{ type: 'single' }"
    @data-source-change="profile = $event"
  />
</template>

API ​

属性 ​

属性类型默认值说明 / 来源
columnsProDescriptionsColumn<T>[][]字段描述，见字段配置。
dataSourceT{}单条记录；通过 dataSourceChange 接收保存结果。
request(params: P) => Promise<{ data: T; success?: boolean }>—挂载及 request/params 变化时请求；只接纳最新响应，success=false 不更新。
paramsP{}顶层记录请求参数。
loadingboolean—显式覆盖内部请求加载状态，传给 Spin。
titleVNodeChild—标题；title 插槽优先。
tooltipstring | TooltipProps—标题提示，传给原生 Tooltip。
extraVNodeChild—附加区域；extra 插槽优先。
editablefalse | EditableConfig<T>—启用逐字段编辑；本组件实际消费的子项见编辑配置。
formPropsFormProps—传给编辑 Form；合并 editable.formProps，后者优先，model 最终由内部草稿覆盖。
formRefRef<FormInstance | undefined>—获得实际原生 FormInstance，不是 ProFormInstance。
actionRefRef<ProDescriptionsInstance<T> | undefined>—接收本组件实例，等同组件 ref。
emptyTextVNodeChild—传给 ProField 的空值占位。
prefixClsstringant-pro-descriptions完整公开前缀，继承 Pro 与原生配置。
classesSemanticClasses | ({ props }) => SemanticClasses—原生 Descriptions 语义类名，优先于 classNames。
classNamesSemanticClasses | ({ props }) => SemanticClasses—旧语义类名入口。
stylesSemanticStyles | ({ props }) => SemanticStyles—原生 Descriptions 语义样式；content 默认 minWidth=0。
onLoadingChange(loading: boolean) => void—内部请求 loading 变化回调。
onRequestError(error: unknown) => void—顶层请求失败，对应 requestError 事件。
onDataSourceChange(data: T) => void—字段保存后完整记录，对应 dataSourceChange。
onEditableError(error: unknown) => void—编辑校验/保存/取消异常，对应 editableError。

其他 Descriptions 属性，如 bordered、column、size、layout、colon、labelStyle/contentStyle，直接透传。公开类型替换 items/title/extra/prefixCls/classes/styles，应使用 columns 及上表入口。

字段配置 ​

属性类型默认值说明 / 来源
keyProKey—编辑标识；优先于 dataIndex 派生值。
dataIndexProDataIndex—记录字段路径；嵌套字段用数组。
titleVNodeChild | ((column) => VNodeChild)—字段标签，省略时回退 label。
labelVNodeChild—title 的回退标签。

ordernumber0降序排列，值大者优先。
hidebooleanfalse隐藏此字段。
hideInDescriptionsbooleanfalse隐藏此描述字段。

valueEnumProValueEnum | (() => ProValueEnum)—枚举标签及选项，见 ProField。
fieldPropsRecord<string, unknown> | ((record?: T) => Record<string, unknown>)—传给 valueType 对应控件，函数收到当前记录。
request(params?) => Promise<Record<string, unknown>[]>—字段选项请求，不替代顶层记录 request。
onFieldRequestError(error: unknown) => void—字段选项请求失败。
paramsRecord<string, unknown>{}字段选项请求参数。
dependenciesProDataIndex[]—将依赖路径值合并进字段请求 params，自定义编辑 context 同时提供依赖值。

ellipsisTableColumnType<T>['ellipsis']—只读值省略展示，见 ProField。
readonlybooleanfalse禁止进入本组件编辑流程。
editableboolean | ((record: T, index: number) => boolean)true顶层 editable 开启后决定此字段能否编辑。
mode'read' | 'edit' | 'update'read传给 FieldRender；进入本组件编辑流程后强制 edit。
plainbooleanfalse共享类型保留项，当前组件未消费。
formItemPropsRecord<string, unknown> | ((record?: T) => Record<string, unknown>)—编辑 FormItem 配置；函数收到草稿；name 和 marginBottom 最终由组件指定。
renderText(value, record, index, action) => unknown—默认渲染前转换值。
render(dom, record, index, action, schema) => VNodeChild—自定义只读节点，dom 为 ProField 默认节点。
formItemRender(schema, context, form: FormInstance | undefined) => VNodeChild—自定义编辑；用 context.update(value) 回写草稿。
renderFormItem(schema, context) => VNodeChild—兼容回退；formItemRender 优先。

类型继承 ProColumns。表格专用项（width/minWidth/fixed/align/sorter/filters/hideInTable/hideInSearch/hideInForm/search/colSize）、嵌套 columns/children、initialValue、convertValue、transform 不由当前描述渲染器处理；需要时通过原生表单配置或自定义渲染实现。

编辑 context 包含 record/index/column/editable/isEditable/recordKey/type="descriptions"/dependencies/defaultRender()/update(value)。form 为实际原生 FormInstance。

编辑配置 ​

属性类型默认值说明 / 来源
type'single' | 'multiple'single同时编辑单个或多个字段。
editableKeysProKey[]—受控编辑字段 key；在 onChange 中回写。
onChange(keys: ProKey[], rows: T[]) => void—编辑 key 改变；rows 是只包含当前完整草稿的数组。
onValuesChange(record: T, rows: T[]) => void—草稿变化；rows=[record]。
onSave(key, next: T, origin: T) => void | boolean | Promise<void | boolean>—只校验和合并当前字段；false 或异常保留编辑。
onCancel(key, draft: T, origin: T) => void | Promise<void>—取消当前字段，并恢复其原值。
formPropsFormProps—原生 Form 配置，优先于顶层 formProps，内部 model 优先。
formRefRef<FormInstance | undefined>—与顶层 formRef 均能获得实际原生实例。

共享 EditableConfig 类型中的 onDelete/actionRender/form、操作文案及新增/单行告警选项由表格使用，ProDescriptions 不消费；本组件保存/取消按钮使用 Pro locale 文案。保存只校验当前字段，onSave=false 或校验失败继续编辑；受控 key 仍须父组件回写。

事件与回调 ​

事件 / 回调参数说明
dataSourceChange(data: T)保存后完整记录；调用方负责持久化并更新数据。
requestError(error: unknown)顶层请求异常。
editableError(error: unknown)校验、保存、取消异常。
onLoadingChange(loading: boolean)内部请求 loading 变化。
editable 回调编辑配置编辑键、草稿变化、保存和取消生命周期。

插槽 ​

插槽参数说明
title—替换 title；tooltip 仍渲染。
extra—替换 extra。
field-${columnKey}{ record: T, column: ProDescriptionsColumn<T> }只读字段区域；columnKey 从 key/dataIndex 派生。

实例 ​

成员参数 / 返回值说明
reload()() => Promise<void>用当前 params 重新请求。
getData()() => T读取当前完整记录。
dataSourcereadonly T | undefined当前记录 getter。
setDataSource(data)(T | undefined) => void替换记录和草稿；undefined 置为 {}。
startEditable(key)(ProKey) => boolean允许时进入字段编辑。
saveEditable(key)(ProKey) => Promise<boolean>校验保存字段；阻止或失败时 false。

isEditable(key)(ProKey) => boolean检查字段编辑状态。

原生描述项成员 ​

ProDescriptions.Item 与 ProDescriptionsItem 均是原生 Descriptions.Item 别名，key/label/children/span 及原生插槽遵循该 API，不新增 Pro 事件和实例方法。默认插槽原生项不自动成为可编辑 Schema 字段。

FieldRender ​

属性类型默认值说明 / 来源
entityT必填当前完整记录。
actionProDescriptionsInstance<T>必填当前描述实例，传给渲染回调。
textunknown—当前字段值；支持 v-model:text。
indexnumber0当前字段下标。
formFormInstance—传给自定义编辑回调的原生表单。
emptyTextVNodeChild—ProField 空值占位。
其余属性类型 / 来源说明
dataIndex / title / label字段配置传入渲染回调的 schema 标识及标签。
valueType / valueEnum / request / params / dependencies / fieldProps / renderText / render / formItemRender / renderFormItem / copyable / ellipsis / mode / onFieldRequestError字段配置签名和默认值同上，mode 默认 read。
formItemProps原生 FormItem包含在回调 schema 中；独立 FieldRender 不创建 FormItem。
事件 / 回调参数说明
update:text(value: unknown)回传默认或自定义编辑变化。
onFieldRequestError(error: unknown)字段选项请求失败。

FieldRender 无额外插槽或实例方法，不创建表单、不负责保存。classes/styles 的部位遵循原生 Descriptions 语义结构，Pro token 见 ProConfigProvider。
