组件/工具栏与辅助组件

工具栏与辅助组件 ​

可独立组合的工具栏、操作菜单、查询表单、筛选浮层、字段标签与错误展示组件。全部从 @bubblesjs/antdv-next-pro 公开导出。

vue
<script setup lang="ts">
import { computed, defineComponent, h, ref } from 'vue'
import { Button, Form, Input, Space } from 'antdv-next'
import {
  DropdownFooter,
  ErrorBoundary,
  FieldLabel,
  FilterDropdown,
  InlineErrorFormItem,
  LabelIconTip,
  LightWrapper,
  ListToolBar,
  ProForm,
  ProFormText,
  Search,
  TableDropdown,
  type ProColumns,
} from '@bubblesjs/antdv-next-pro'

const DropdownButton = TableDropdown.Button
const feedback = ref('操作工具栏、筛选标签与错误恢复，结果会显示在这里。')
const dropdownOpen = ref(false)
const filterDraft = ref('进行中')
const filterValue = ref<string>()
const name = ref('')
const inlineModel = computed(() => ({ name: name.value }))
const showError = ref(false)
const error = computed(() =>
  showError.value && name.value.trim().length < 2 ? '请至少输入两个字符' : undefined,
)
const crash = ref(false)
const CrashContent = defineComponent({
  props: { fail: Boolean },
  setup(props) {
    return () => {
      if (props.fail) throw new Error('这是用于演示恢复流程的错误。')
      return h(
        'p',
        { 'data-demo-boundary-content': '' },
        '内容正常，点击“触发错误”查看自定义降级界面。',
      )
    }
  },
})
const searchColumns: ProColumns[] = [
  { title: '项目名称', dataIndex: 'name' },
  {
    title: '状态',
    dataIndex: 'status',
    valueType: 'select',
    valueEnum: { active: '进行中', done: '已完成' },
  },
]
const filterFooter = {
  onConfirm: () => {
    filterValue.value = filterDraft.value
    feedback.value = `已应用筛选：${filterDraft.value}`
    dropdownOpen.value = false
  },
  onClear: () => {
    filterDraft.value = ''
    filterValue.value = undefined
    feedback.value = '已清除筛选'
  },
}
async function submitLight(values: Record<string, unknown>) {
  feedback.value = `轻量筛选：${JSON.stringify(values)}`
  return true
}
function validateName() {
  showError.value = true
  feedback.value = name.value.trim().length >= 2 ? '名称校验通过' : '名称校验未通过'
}
function recover(reset: () => void) {
  crash.value = false
  reset()
}
</script>

<template>
  <div class="shared-demo" data-demo="shared-components">
    <section>
      <ListToolBar
        title="独立工具栏"
        sub-title="下拉操作与搜索"
        tooltip="此处展示公开的辅助组件。"
        :search="{
          placeholder: '输入工具栏关键词',
          onSearch: (value: string) => {
            feedback = `工具栏搜索：${value}`
          },
        }"
      >
        <template #actions>
          <TableDropdown
            text="更多操作"
            :menus="[
              { key: 'export', name: '导出列表' },
              { key: 'archive', name: '归档项目' },
            ]"
            :on-select="
              (key: string) => {
                feedback = `选中菜单：${key}`
              }
            "
          />
          <DropdownButton
            text="按钮菜单"
            :menus="[{ key: 'copy', name: '复制链接' }]"
            :on-select="
              (key: string) => {
                feedback = `按钮菜单：${key}`
              }
            "
            data-demo-dropdown-button
          />
        </template>
      </ListToolBar>
      <Search
        :columns="searchColumns"
        :search="{ defaultCollapsed: false, searchText: '应用查询' }"
        @submit="feedback = `查询条件：${JSON.stringify($event)}`"
        @reset="feedback = '查询已重置'"
      />
    </section>

    <section>
      <h3>
        <LabelIconTip
          label="筛选与提示"
          sub-title="点击标签打开筛选"
          tooltip="确认应用修改，取消保留上次结果。"
        />
      </h3>
      <Space wrap>
        <FilterDropdown
          v-model:open="dropdownOpen"
          label="状态筛选"
          :footer="filterFooter"
          placement="bottomLeft"
        >
          <template #label><Button data-demo-filter-open>状态筛选</Button></template>
          <Input v-model:value="filterDraft" aria-label="筛选状态" data-demo-filter-input />
        </FilterDropdown>
        <FieldLabel
          label="已选状态"
          :value="filterValue"
          :on-clear="
            () => {
              filterValue = undefined
              feedback = '已清除标签'
            }
          "
        />
      </Space>
      <ProForm
        :submitter="false"
        :initial-values="{ keyword: '组件' }"
        :on-finish="submitLight"
        class="light-form"
      >
        <LightWrapper name="keyword" label="关键词">
          <ProFormText
            name="keyword"
            placeholder="输入关键词"
            :rules="[{ max: 12, message: '最多输入 12 个字符' }]"
          />
        </LightWrapper>
      </ProForm>
      <div class="footer-preview">
        <span>独立 DropdownFooter</span>
        <DropdownFooter
          clear-text="清除结果"
          confirm-text="确认结果"
          :on-clear="
            () => {
              feedback = '独立操作区：已清除'
            }
          "
          :on-confirm="
            () => {
              feedback = '独立操作区：已确认'
            }
          "
        />
      </div>
    </section>

    <section>
      <h3>行内校验</h3>
      <Form :model="inlineModel" layout="vertical">
        <InlineErrorFormItem label="显示名称" name="name" :error="error">
          <Input v-model:value="name" placeholder="至少两个字符" data-demo-inline-input />
        </InlineErrorFormItem>
        <Button data-demo-inline-validate @click="validateName">校验名称</Button>
      </Form>
    </section>

    <section>
      <h3>错误边界</h3>
      <Button data-demo-boundary-crash :disabled="crash" @click="crash = true">触发错误</Button>
      <ErrorBoundary
        :on-error="
          () => {
            feedback = '错误已被边界捕获，可点击恢复'
          }
        "
      >
        <CrashContent :fail="crash" />
        <template #fallback="{ error: boundaryError, reset }">
          <div role="alert" class="fallback">
            <p>{{ boundaryError.message }}</p>
            <Button data-demo-boundary-reset @click="recover(reset)">恢复内容</Button>
          </div>
        </template>
      </ErrorBoundary>
    </section>
    <p data-demo-shared-state aria-live="polite">{{ feedback }}</p>
  </div>
</template>

最小用法 ​

vue
<script setup lang="ts">
import { ref } from 'vue'
import { Button, Input } from 'antdv-next'
import { LightWrapper, ListToolBar, TableDropdown } from '@bubblesjs/antdv-next-pro'

const open = ref(false)
const keyword = ref('')
const selected = ref('')
const menus = [
  { key: 'export', name: '导出' },
  { key: 'archive', name: '归档' },
]
</script>

<template>
  <ListToolBar title="项目">
    <template #actions>
      <TableDropdown :menus="menus" @select="selected = $event" />
      <Button type="primary">新建</Button>
    </template>
  </ListToolBar>
  <LightWrapper
    v-model:open="open"
    label="关键字"
    :value="keyword"
    allow-clear
    @clear="keyword = ''"
  >
    <Input v-model:value="keyword" />
  </LightWrapper>
  <p>菜单选择：{{ selected }}</p>
</template>

ListToolBar ​

属性说明
title / subTitle / tooltip标题、副标题与提示
actions / settings操作节点或 actions()、设置节点数组
searchboolean 或原生 InputSearch 配置；支持异步 onSearch(value)
menu{ type?, items?, activeKey?, defaultActiveKey?, onChange? }；type 为 inline、tab 或 dropdown
tabs{ items?, activeKey?, defaultActiveKey?, onChange? }，额外一行的标签页
filter / multipleLine过滤节点、多行样式

search.onSearch 返回 false 时不再发出组件 search(value) 事件。menu.onChange(key)、tabs.onChange(key) 提供选择变化通知；受控 activeKey 由调用方更新。

插槽：title、actions、settings、filter。语义部位：root、container、left、right、title、subTitle、extraLine。无独立实例方法。

TableDropdown / TableDropdown.Button ​

属性说明
menus / options{ key: string, name?, label?, disabled?, danger? }[]；menus 优先
text触发文案
disabled禁用菜单
onSelect(key) / @select选择可用菜单项时回传字符串 key

label 优先于 name。默认插槽替换普通 TableDropdown 的触发内容；未提供时使用省略号图标。TableDropdown.Button 是真实组件成员，也可具名导入 TableDropdownButton；它使用原生 Button 作为触发器，额外原生 Button 属性通过 attrs 传入。语义部位为 root；无独立实例方法。

Search ​

独立 schema 查询区，search.filterType="light" 使用 LightFilter，否则使用 QueryFilter。

属性/事件说明
columnsProColumns<T>[]；排除 hideInSearch=true 或 search=false 的列
searchProTable 查询配置：span、labelWidth、collapsed、defaultCollapsed、searchText、resetText、optionRender、collapseRender 等
form原生表单配置，以及 initialValues、submitter；classes/styles 定制筛选表单
formRefRef<SchemaFormInstance<T> | undefined>
submit(values) / reset() / collapse(collapsed)提交、重置、折叠通知

loading 控制默认提交按钮的加载状态；ProTable 内嵌的 Search 自动接收表格请求状态。显式 form.submitter.submitButtonProps.loading 优先，submitter=false 或 submitButtonProps=false 仍会隐藏对应操作。

组件 ref 转发 SchemaFormInstance。Search 只收集并校验查询条件，请求由调用方处理。未额外定义业务插槽或独立语义部位。

FilterDropdown ​

属性/事件说明
label / disabled / placement触发内容、禁用与浮层位置
open / v-model:open不传时组件内部控制；传入时由调用方接受 update:open
popoverProps原生 Popover 属性，原生 onOpenChange 与组件事件合并
footerDropdownFooter 配置；传入时显示操作区
footerRenderfalse 隐藏底部，或替换底部内容的函数
padding内容内边距
openChange(open)打开状态请求变化通知

默认插槽为面板内容，label 插槽为触发内容。语义部位是 root（触发节点）、content（浮层内容）；浮层容器可通过 popoverProps.styles.container 定制。footer 回调负责清空数据与关闭面板，组件不自动执行业务修改。无独立实例方法。

LightWrapper ​

组合 FieldLabel 与 FilterDropdown。属性：label、value、open、disabled、allowClear、footerRender、placement。默认插槽为面板内容，语义部位为 root、content。

事件：update:open、clear、confirm。确认发出 confirm 并请求关闭；清除只发出 clear，由调用方修改 value。open 未传时内部控制，可用 v-model:open 受控。无独立实例方法。

DropdownFooter ​

属性：disabled、confirmText、clearText、onConfirm(event?)、onClear(event?)、footerRender。不提供业务插槽或实例方法。

footerRender=false 不渲染；函数签名为 (confirm?, clear?) => VNodeChild。回调只通知操作，不负责异步等待、清空数据或关闭外层容器。语义部位：root、clear、confirm；自定义 footerRender 替换默认按钮后，按钮部位不再生效。

FieldLabel / LabelIconTip ​

组件属性与行为插槽语义部位
FieldLabellabel、value、disabled、expanded、ellipsis、onClear；值非 null 时展示；expanded 提供展开语义，由父组件控制面板无root、label、value
LabelIconTiplabel、tooltip（字符串或原生 TooltipProps）、subTitle、ellipsis默认插槽替换 labelroot、label、subTitle、tooltip

FieldLabel 使用可聚焦按钮；有值且提供 onClear 时显示清除入口，清除阻止冒泡，否则显示箭头。两者无独立实例方法。

InlineErrorFormItem ​

继承原生 FormItem 属性，增加 error、errorType="default" | "popover"。默认显示内联错误；popover 模式根据 error 的真值展示浮层，并隐藏内联 help。

默认插槽放输入控件，error 插槽自定义内联或浮层错误内容；单独提供 error 插槽不会使空 error 自动打开浮层。语义部位为 root、field（原生 FormItem）。它提供错误展示，校验规则仍由原生 Form/FormItem 执行，无独立实例方法。

ErrorBoundary ​

捕获后代 Vue 组件渲染和生命周期中的错误，展示降级内容。

API说明
fallback节点或 (error, reset) => VNodeChild
resetKeys数组元素变化时重置错误状态
onError(error, info)错误通知
默认插槽正常内容
fallback 插槽{ error, reset }，优先于 fallback 属性
ref.reset()清除错误，重新渲染后代

默认降级内容使用原生 Result 与重试按钮。语义部位 root 只在降级状态存在；正常状态直接渲染默认插槽。自身错误及脱离组件链的异步 Promise、网络失败应由调用方处理。

统一样式与配置 ​

除 Search 使用其表单配置外，上述组件提供 prefixCls、classes、styles；后两者支持对象或 ({ props }) => map。旧 classNames 兼容，同名部位 classes 优先。仅文档列出的部位有实际消费。

组件默认公开前缀
ListToolBarant-pro-table-list-toolbar
TableDropdown / TableDropdown.Buttonant-pro-table-dropdown
LightWrapperant-pro-field-light-wrapper
FilterDropdownant-pro-core-field-dropdown
DropdownFooterant-pro-core-field-dropdown-footer
FieldLabelant-pro-core-field-label
LabelIconTipant-pro-core-label-tip
InlineErrorFormItemant-pro-form-inline-error-form-item
ErrorBoundaryant-pro-error-boundary

原生 ConfigProvider 设置 prefixCls="demo" 后，以上 ant-pro 部分变为 demo-pro，也可用组件 prefixCls 覆盖。

语言、方向、主题算法及原生组件 token 继承 ConfigProvider；Pro 扩展 token 使用 ProConfigProvider.token。原生 Result 的定制使用 theme.components.Result，辅助组件没有独立注册 theme.components.ProX 入口。
