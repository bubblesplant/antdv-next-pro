组件/QueryFilter 查询筛选

QueryFilter 查询筛选 ​

QueryFilter 是可独立使用的查询表单，支持响应式栅格、查询、重置及展开收起。ProTable 的默认搜索区域也使用这个组件。可以组合 ProForm 字段，也可以传入 columns 生成字段。

默认使用横向表单布局，根容器内边距和字段行间距均为 24px，字段不额外叠加 Form.Item 的底部间距。可显式设置 layout="vertical"；styles.root/row/item/actions 可定制对应区域。

引入 ​

ts
import { QueryFilter, ProFormText, ProFormSelect } from '@bubblesjs/antdv-next-pro'
import '@bubblesjs/antdv-next-pro/style.css'

也可以通过 app.use(AntdvNextPro) 全局注册，使用 <QueryFilter>；配置方式见快速开始。

组合字段与展开收起 ​

默认插槽直接放置 ProFormText、ProFormSelect 等字段；通过 v-model 读取条件，使用 :on-finish="search" 处理校验成功后的查询。

查看完整代码
vue
<script setup lang="ts">
import { ref } from 'vue'
import { ProFormSelect, ProFormText, QueryFilter } from '@bubblesjs/antdv-next-pro'

const initialValues = { status: 'active' }
const model = ref<Record<string, unknown>>({ ...initialValues })
const collapsed = ref(true)
const submitted = ref('')
const count = ref(0)

function search(values: Record<string, unknown>) {
  submitted.value = JSON.stringify(values, null, 2)
  count.value++
  return true
}
</script>

<template>
  <div>
    <QueryFilter
      v-model="model"
      v-model:collapsed="collapsed"
      :initial-values="initialValues"
      :span="8"
      :label-width="80"
      :on-finish="search"
      @reset="submitted = ''"
    >
      <ProFormText name="keyword" label="项目名称" :field-props="{ placeholder: '请输入关键词' }" />
      <ProFormSelect
        name="status"
        label="项目状态"
        :options="[
          { label: '进行中', value: 'active' },
          { label: '已完成', value: 'done' },
        ]"
      />
      <ProFormText name="owner" label="负责人" :field-props="{ placeholder: '展开后填写负责人' }" />
      <ProFormSelect
        name="priority"
        label="优先级"
        :options="[
          { label: '普通', value: 'normal' },
          { label: '紧急', value: 'urgent' },
        ]"
      />
    </QueryFilter>
    <div class="filter-result" aria-live="polite">
      <p>查询区{{ collapsed ? '已收起' : '已展开' }} · 已查询 {{ count }} 次</p>
      <span>{{ submitted ? '最近一次查询参数' : '当前表单值' }}</span>
      <pre>{{ submitted || JSON.stringify(model, null, 2) }}</pre>
    </div>
  </div>
</template>

<style scoped>
.filter-result {
  margin-top: 20px;
  padding: 16px;
  border: 1px solid #e8ecf1;
  border-radius: 6px;
  background: #fafbfc;
  color: #64748b;
  font-size: 12px;
}
.filter-result p {
  margin: 0 0 12px;
}
.filter-result pre {
  margin: 8px 0 0;
  overflow: auto;
  color: #334155;
}
</style>

defaultCollapsed 默认为 true，v-model:collapsed 可受控切换。字段超过首行容量时显示折叠按钮，展开向下、收起向上，默认箭头随状态旋转；收起会隐藏字段并保留值。

span 使用 24 栅格，可传数字或断点对象，例如 { xs: 24, sm: 12, md: 8 }。不设置时，根据容器宽度和 defaultColsNumber 调整列宽。

columns 与实例方法 ​

已有 Schema 配置时，直接传入 columns。通过 ref 可设置条件、提交和重置，无需依赖表格实例。

查看完整代码
vue
<script setup lang="ts">
import { ref } from 'vue'
import { Button, Space } from 'antdv-next'
import {
  QueryFilter,
  type SchemaFormColumn,
  type SchemaFormInstance,
} from '@bubblesjs/antdv-next-pro'

type Filters = Record<string, unknown> & { keyword?: string; owner?: string; status?: string }
const form = ref<SchemaFormInstance<Filters>>()
const model = ref<Partial<Filters>>({})
const submitted = ref('')
const columns: SchemaFormColumn<Filters>[] = [
  { title: '项目名称', dataIndex: 'keyword', fieldProps: { placeholder: '请输入项目名称' } },
  {
    title: '项目状态',
    dataIndex: 'status',
    valueType: 'select',
    valueEnum: { active: '进行中', done: '已完成' },
  },
  { title: '负责人', dataIndex: 'owner', fieldProps: { placeholder: '请输入负责人' } },
]

function search(values: Partial<Filters>) {
  submitted.value = JSON.stringify(values, null, 2)
  return true
}
</script>

<template>
  <div>
    <Space style="margin-bottom: 16px" wrap>
      <Button @click="form?.setFieldsValue({ keyword: '组件升级', status: 'active' })">
        填入示例条件
      </Button>
      <Button @click="form?.submit()">通过 ref 查询</Button>
      <Button @click="form?.reset()">通过 ref 重置</Button>
    </Space>
    <QueryFilter
      ref="form"
      v-model="model"
      :columns="columns"
      :default-collapsed="false"
      :on-finish="search"
      @reset="submitted = ''"
    />
    <pre class="filter-result" aria-live="polite">{{
      submitted || JSON.stringify(model, null, 2)
    }}</pre>
  </div>
</template>

<style scoped>
.filter-result {
  margin-top: 20px;
  overflow: auto;
  padding: 16px;
  border: 1px solid #e8ecf1;
  border-radius: 6px;
  background: #fafbfc;
  color: #334155;
  font-size: 12px;
}
</style>

columns 的字段配置见 SchemaForm。组合字段和 columns 是两种字段声明方式，示例中分别使用。

API ​

除下表外，还支持 ProForm 的 initialValues、request、params、校验、格式转换和 URL 同步等公共配置。

属性类型默认值 / 说明
modelValue / v-modelPartial<T>当前查询条件
columnsSchemaFormColumn<T>[]可选，配置 Schema 字段
onFinish(values) => boolean | void | Promise<boolean | void>校验成功后的查询回调，使用 :on-finish 绑定
collapsed / v-model:collapsedboolean受控折叠状态
defaultCollapsedbooleantrue
defaultColsNumbernumber3，较宽容器的默认列数
spannumber | Record<string, number>24 栅格列宽，断点为 xs/sm/md/lg/xl
labelWidthnumber | 'auto'标签宽度，默认 80，数字单位为 px
splitbooleanfalse，分隔样式
searchText / resetTextVNodeChild默认使用国际化查询 / 重置文案
optionRenderfalse | (props, form, doms) => VNodeChild定制查询、重置操作；false 隐藏操作按钮
collapseRenderfalse | (collapsed) => VNodeChild定制折叠按钮内容；false 隐藏折叠按钮
submitterfalse | SubmitterProps配置查询、重置按钮及自定义渲染

optionRender=false 不会隐藏折叠按钮；需要隐藏折叠按钮时设置 collapseRender=false。自定义 collapseRender 会替换默认文案和箭头。

事件说明
update:modelValue / change查询条件变化
update:collapsed / collapse参数为最新的折叠状态
submit观察提交；需要等待业务结果时使用 onFinish
reset重置到初始化快照
error / requestError提交错误 / 初始化请求错误

默认插槽用于组合字段。ref 可使用 SchemaFormInstance<T>，提供 getFieldsValue()、setFieldsValue()、validate()、submit()、reset() 等方法，详见 ProForm 实例。

与其他组件配合 ​

  • 表格搜索使用 ProTable 的 search 配置，见 ProTable。
  • 标签弹层形式的筛选使用 LightFilter。
  • 国际化、主题与语义样式沿用 ProForm。
