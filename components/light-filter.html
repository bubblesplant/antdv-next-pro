组件/LightFilter 轻量筛选

LightFilter 轻量筛选 ​

LightFilter 是可独立使用的标签式筛选表单，点击字段标签打开弹层，确认后提交查询。ProTable 设置 search.filterType='light' 时也使用这个组件。

引入 ​

ts
import { LightFilter, ProFormText, ProFormSelect } from '@bubblesjs/antdv-next-pro'
import '@bubblesjs/antdv-next-pro/style.css'

也可以通过 app.use(AntdvNextPro) 全局注册，使用 <LightFilter>；配置方式见快速开始。

标签筛选与更多条件 ​

默认插槽组合 ProForm 字段，普通字段分别显示筛选标签；字段设置 secondary 后进入“更多筛选”。通过 v-model 读取条件，使用 :on-finish="search" 处理查询。

查看完整代码
vue
<script setup lang="ts">
import { ref } from 'vue'
import { LightFilter, ProFormSelect, ProFormText } from '@bubblesjs/antdv-next-pro'

const model = ref<Record<string, unknown>>({})
const submitted = ref('')
const count = ref(0)

function search(values: Record<string, unknown>) {
  submitted.value = JSON.stringify(values, null, 2)
  count.value++
  return true
}
</script>

<template>
  <div>
    <LightFilter v-model="model" :on-finish="search">
      <ProFormText
        name="keyword"
        label="项目名称"
        :field-props="{ placeholder: '输入后点击确认' }"
      />
      <ProFormSelect
        name="status"
        label="项目状态"
        :options="[
          { label: '进行中', value: 'active' },
          { label: '已完成', value: 'done' },
        ]"
      />
      <ProFormText
        name="owner"
        label="负责人"
        secondary
        :field-props="{ placeholder: '在更多筛选中填写' }"
      />
    </LightFilter>
    <div class="filter-result" aria-live="polite">
      <p>已查询 {{ count }} 次 · 确认应用条件，关闭弹层取消本次编辑，清除后重新查询。</p>
      <span>{{ submitted ? '最近一次查询参数' : '当前表单值' }}</span>
      <pre>{{ submitted || JSON.stringify(model, null, 2) }}</pre>
    </div>
  </div>
</template>

弹层中确认会先校验，再提交查询；未确认就关闭弹层会恢复打开时的值。清除会移除当前字段或分组的条件并重新提交。输入过程中 v-model 会变化，查询在确认或清除时触发。

收起全部条件 ​

collapse=true 将全部字段收进同一个弹层，collapseLabel 设置入口文案。需要恢复所有初始条件时，可通过 ref 调用 reset()。

查看完整代码
vue
<script setup lang="ts">
import { ref } from 'vue'
import { Button, Space } from 'antdv-next'
import {
  LightFilter,
  ProFormSelect,
  ProFormText,
  type ProFormInstance,
} from '@bubblesjs/antdv-next-pro'

const form = ref<ProFormInstance>()
const model = ref<Record<string, unknown>>({})
const submitted = ref('')

function search(values: Record<string, unknown>) {
  submitted.value = JSON.stringify(values, null, 2)
  return true
}
</script>

<template>
  <div>
    <Space align="start" wrap>
      <LightFilter
        ref="form"
        v-model="model"
        collapse
        collapse-label="筛选项目"
        placement="bottomLeft"
        :on-finish="search"
        @reset="submitted = ''"
      >
        <ProFormText
          name="keyword"
          label="项目名称"
          :field-props="{ placeholder: '请输入项目名称' }"
        />
        <ProFormSelect
          name="status"
          label="项目状态"
          :options="[
            { label: '进行中', value: 'active' },
            { label: '已完成', value: 'done' },
          ]"
        />
        <ProFormText name="owner" label="负责人" />
      </LightFilter>
      <Button @click="form?.reset()">重置全部条件</Button>
    </Space>
    <pre class="filter-result" aria-live="polite">{{
      submitted || JSON.stringify(model, null, 2)
    }}</pre>
  </div>
</template>

<style scoped>
.filter-result {
  margin-top: 20px;
  overflow: auto;
  padding: 16px;
  border: 1px solid #e8ecf1;
  border-radius: 6px;
  background: #fafbfc;
  color: #334155;
  font-size: 12px;
}
</style>

使用 columns ​

与 QueryFilter 一样，可以直接传入 SchemaForm columns，无需声明字段子组件：

vue
<script setup lang="ts">
import { ref } from 'vue'
import { LightFilter, type SchemaFormColumn } from '@bubblesjs/antdv-next-pro'

const filters = ref<Record<string, unknown>>({})
const columns: SchemaFormColumn[] = [
  { title: '项目名称', dataIndex: 'keyword' },
  {
    title: '项目状态',
    dataIndex: 'status',
    valueType: 'select',
    valueEnum: { active: '进行中', done: '已完成' },
  },
]

function search(values: Record<string, unknown>) {
  console.log(values)
  return true
}
</script>

<template>
  <LightFilter v-model="filters" :columns="columns" :on-finish="search" />
</template>

API ​

属性 ​

未传 columns 时组合字段，传入时走 BetaSchemaForm。公共配置及透传入口如下：

配置入口类型归属与完整文档
ProForm 公共属性ProFormProps<T>initialValues/request/params/readonly/disabled/dateFormatter/syncToUrl/syncToInitialValues/onValuesChange/formRef/prefixCls/classes/classNames/styles 等见 ProForm 属性
组合模式的原生 Form 属性FormProps直接写在 LightFilter；校验/标签/布局属性见 antdv-next Form API
formProps（columns 模式）Partial<FormProps>传给 Schema 内部原生 Form；Form API及 SchemaForm 属性。模型、提交、readonly 与筛选布局由上层协调
columns 模式其余配置SchemaFormProps<T>见 SchemaForm 属性；fieldProps/formItemProps 的基础组件归属见字段 API
属性类型默认值说明 / 来源
modelValuePartial<T>—当前查询值，支持 v-model
columnsSchemaFormColumn<T>[]—启用 Schema 模式；列配置
onFinish(values: T) => boolean | void | Promise<boolean | void>—确认或清除后的业务查询；使用 :on-finish
collapsebooleanfalse所有字段收入同一个“更多筛选”弹层
collapseLabelVNodeChild国际化“更多筛选”收起入口文案
placementPopoverProps['placement']'bottomLeft'Popover 位置
footerRenderfalse | ({ confirm, clear }, doms) => VNodeChild默认确认/清除按钮定制弹层底部；false 隐藏；回调中的 confirm/clear 执行标准流程
字段 secondarybooleanfalse写在字段子组件或 Schema 列上，由 LightFilter 读取；将该字段放入更多筛选

collapse 为分组配置，不使用 QueryFilter 的 v-model:collapsed。confirm 先校验再提交；取消恢复打开时的值；clear 清除字段后提交。输入过程中 v-model 变化，查询在确认/清除时发生。LightFilter 使用弹层 footerRender 管理操作区；submitter 的公共配置定义见 ProForm，它不替代这里的弹层底部。

事件 ​

事件参数说明
update:modelValuevalues: Partial<T>受控值变化，包括尚未确认的编辑
changevalues: Partial<T>条件变化
submitvalues: Partial<T>提交通知；业务等待通过 onFinish
resetvalues: Partial<T>实例重置为初始化快照

requestErrorerror: unknown初始化请求失败
Schema 专属事件见 SchemaForm 事件columns 模式支持 valuesChange、fieldChange、finish 等，触发规则见来源文档

插槽 ​

插槽参数说明
default无组合模式的字段子组件
动态字段插槽（columns 模式）SchemaForm 插槽上下文field-${path}、字段路径与列 key 对应的渲染入口

LightFilter 弹层操作通过 footerRender 定制，不提供 submitter 插槽操作区。单字段弹层的标签插槽见 LightWrapper。

实例方法 ​

公开布局 ref 类型为 SchemaFormInstance<T>；完整签名与行为见 SchemaForm 实例和 ProForm 实例。

方法 / 属性返回值说明
nativeFormFormInstance | undefined底层 Form 实例

getFieldsFormatValue() / getFieldFormatValue(name)Partial<T> / unknown格式化与 transform 后结果
setFieldsValue(values) / setFieldValue(name, value)void更新值
submit()Promise<Partial<T>>校验并等待查询回调

统一 ref 还有服务其他布局的 open/close/next/prev/formMap；它们不用于控制筛选弹层，单个弹层通过 LightWrapper 的 open 控制。

LightWrapper ​

根入口导出的 LightWrapper 是与 ProForm 上下文协作的筛选弹层。它读取 name/fieldNames 对应的表单值，保存打开快照，并在取消时恢复；独立使用时请放入 ProForm。

属性 ​

属性类型默认值说明 / 来源
nameProDataIndex—单字段表单路径
fieldNamesProDataIndex[]—一组字段路径；配置后优先于 name，统一确认/清除
labelVNodeChild空入口标签；label 插槽优先
disabledbooleanfalse禁用入口，亦继承当前表单禁用状态
openboolean非受控弹层显示，支持 v-model:open
placementPopoverProps['placement']'bottomLeft'Popover 位置
footerRender同 LightFilter.footerRender确认/清除按钮自定义底部
其余 attrsPopoverProps / HTML attrs原生值传给 Popover，trigger/open/placement 及打开监听由包装器协调

事件与插槽 ​

类别名称参数 / 用途
事件update:open(open: boolean)，受控打开状态更新
事件confirm(value: unknown)，校验提交成功后通知；分组时为所选字段组成的对象
事件clear无参数，字段已清除，随后触发查询
插槽default无参数，弹层内部字段
插槽label{ value }，自定义入口标签

LightWrapper 没有公开实例方法。确认/清除入口由 footerRender 提供；打开状态通过 v-model:open 控制。它不提供独立 value/allowClear 属性，展示值来自表单上下文。

与其他组件配合 ​

  • 网格形式的查询表单使用 QueryFilter。
  • 表格轻量搜索使用 ProTable 的 search.filterType='light'。
  • 国际化、主题与语义样式沿用 ProForm。
