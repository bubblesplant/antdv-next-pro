Components/AdaptiveProTable

AdaptiveProTable ​

AdaptiveProTable is a separately maintained wrapper around ProTable. It only adds the adaptive-table class and layout styles, forwarding all other props, events, slots and instance methods. The search form, toolbar and pagination keep their natural height, while the table body fills the remaining container space.

Example ​

Change the container height, expand the search form or clear the data to see the body resize without measuring the surrounding controls.

vue
<script setup lang="ts">
import { ref } from 'vue'
import { Button, Space } from 'antdv-next'
import { AdaptiveProTable, type ProColumns, type ProTableInstance } from '@bubblesjs/antdv-next-pro'

interface Project extends Record<string, unknown> {
  id: number
  name: string
  owner: string
  department: string
  status: string
}

const table = ref<ProTableInstance<Project>>()
const height = ref(600)
const empty = ref(false)
const message = ref('调整容器高度或展开查询条件，观察表体高度变化。')
const rows: Project[] = Array.from({ length: 40 }, (_, index) => ({
  id: index + 1,
  name: `项目 ${index + 1}`,
  owner: ['林默', '周芮', '孟晴'][index % 3]!,
  department: ['数据产品', '研发平台'][index % 2]!,
  status: index % 3 === 0 ? 'done' : 'running',
}))
const columns: ProColumns<Project>[] = [
  { title: '项目名称', dataIndex: 'name', width: 240 },
  { title: '负责人', dataIndex: 'owner', width: 160 },
  { title: '所属部门', dataIndex: 'department', width: 220 },
  {
    title: '状态',
    dataIndex: 'status',
    width: 160,
    valueType: 'select',
    valueEnum: {
      running: { text: '进行中', status: 'processing' },
      done: { text: '已完成', status: 'success' },
    },
  },
]

async function reload() {
  await table.value?.reload()
  message.value = '已通过 ProTableInstance.reload() 刷新。'
}
</script>

<template>
  <div class="demo-frame vp-raw">
    <Space wrap class="adaptive-doc-actions">
      <Button @click="height = height === 600 ? 760 : 600">切换高度：{{ height }}px</Button>
      <Button @click="empty = !empty">{{ empty ? '恢复数据' : '清空数据' }}</Button>
      <Button @click="reload">通过 ref 刷新</Button>
    </Space>
    <p class="adaptive-doc-hint">{{ message }}</p>
    <div :style="{ height: `${height}px`, minHeight: 0 }">
      <AdaptiveProTable
        ref="table"
        :columns="columns"
        :data-source="empty ? [] : rows"
        row-key="id"
        header-title="项目清单"
        :search="{ defaultCollapsed: true, span: 12 }"
        :pagination="{ defaultPageSize: 20 }"
        :row-selection="{}"
        :scroll="{ x: 780, y: '100%' }"
        @search-collapse="message = $event ? '已收起查询条件。' : '已展开查询条件，表体自动缩小。'"
      >
        <template #toolbar-actions="{ action, selectedRows }">
          <Button @click="action.reload()">插槽刷新</Button>
          <Button :disabled="!selectedRows.length" @click="action.clearSelected()">
            取消选择（{{ selectedRows.length }}）
          </Button>
        </template>
        <template #cell-name="{ record }"
          ><strong>{{ record.name }}</strong></template
        >
      </AdaptiveProTable>
    </div>
  </div>
</template>

<style scoped>
.adaptive-doc-actions {
  margin-bottom: 8px;
}

.adaptive-doc-hint {
  margin: 0 0 16px;
  color: var(--vp-c-text-2);
  font-size: 13px;
}
</style>

Usage ​

vue
<script setup lang="ts">
import { ref } from 'vue'
import { AdaptiveProTable, type ProColumns, type ProTableInstance } from '@bubblesjs/antdv-next-pro'
import '@bubblesjs/antdv-next-pro/style.css'

type User = { id: number; name: string }
const table = ref<ProTableInstance<User>>()
const columns: ProColumns<User>[] = [{ title: 'Name', dataIndex: 'name' }]
const rows: User[] = [{ id: 1, name: 'Ada' }]
</script>

<template>
  <div style="height: 600px; min-height: 0">
    <AdaptiveProTable
      ref="table"
      :columns="columns"
      :data-source="rows"
      row-key="id"
      :scroll="{ y: '100%' }"
    />
  </div>
</template>

The component is also registered globally by app.use(AntdvNextPro).

Container height ​

Reserve enough height for the expanded search form, toolbar and pagination. On narrow screens, search fields stack vertically and need more space.

The parent must have a definite available height: a fixed height, calc(100vh - 160px), or the remaining space in a bounded flex layout. Set min-height: 0 on intermediate flex items so they can shrink. Use the base ProTable for pages that grow naturally with their content.

API and forwarding ​

This wrapper adds no public business properties. Generic parameters, defaults, controlled behavior and precedence match ProTable; only the adaptive-table class and layout styles are added.

Properties ​

PropertyTypeDefaultDescription and source
classClassValue—Merges caller classes and adds adaptive-table.
styleStyleValue—Passed to the ProTable root.
columnsProColumns<T>[]requiredEvery column property is listed in ProTable columns.
scroll.xnumber | string | true—Forwards horizontal scroll width.
scroll.ynumber | string—Forwards scroll-body height; explicitly set it, e.g. '100%', for internal scrolling.

Instance ​

Instance typeMethods and return types
ProTableInstance<T>Inherits all ProTable methods: reload/reset, pagination, selection, scrolling, fullscreen, editing and row access; adds no methods.

Search, toolbar, pagination and selection alerts keep their natural heights. Styles target the default Card, Spin and Table structure; wrappers added through tableRender/tableViewRender/searchFormRender need matching flex height constraints. Native virtual tables require numeric scroll.y.

Upstream synchronization ​

This is a user-maintained extension in packages/src/adaptive-pro-table/. Preserve this directory, package exports, documentation and playground entries when syncing upstream pro-components. If upstream DOM changes, adapt this wrapper without adding adaptive branches to the base ProTable. See the repository root AGENTS.md for the complete maintenance rules.
