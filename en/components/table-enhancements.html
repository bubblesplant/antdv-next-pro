Components/Table enhancements

Table enhancements ​

DragSortTable, RowEditorTable and CellEditorTable share ProTable schemas, requests, native configuration and semantic styles. They add reordering, row editing and cell editing respectively.

vue
<script setup lang="ts">
import { ref } from 'vue'
import { Button, Space } from 'antdv-next'
import {
  CellEditorTable,
  DragSortTable,
  RowEditorTable,
  type EditableConfig,
  type ProColumns,
  type ProKey,
  type ProTableInstance,
} from '@bubblesjs/antdv-next-pro'

interface Task extends Record<string, unknown> {
  id: number
  name: string
  priority: number
}
const initial: Task[] = [
  { id: 1, name: '编写示例', priority: 1 },
  { id: 2, name: '交互验收', priority: 2 },
  { id: 3, name: '整理文档', priority: 3 },
]
const columns: ProColumns<Task>[] = [
  {
    title: '任务',
    dataIndex: 'name',
    formItemProps: { rules: [{ required: true, message: '请输入任务名称' }] },
  },
  { title: '优先级', dataIndex: 'priority', valueType: 'digit', fieldProps: { min: 1, max: 5 } },
]
const dragRows = ref(initial.map((row) => ({ ...row })))
const rowRows = ref(initial.map((row) => ({ ...row })))
const cellRows = ref(initial.map((row) => ({ ...row })))
const rowAction = ref<ProTableInstance<Task>>()
const cellAction = ref<ProTableInstance<Task>>()
const feedback = ref('拖动手柄排序；也可以聚焦手柄后按上下方向键。')
const editable: EditableConfig<Task> = {
  type: 'single',
  onSave: async (_key, record) => {
    feedback.value = `已保存任务：${record.name}`
    return true
  },
}
function dragEnd(from: number, to: number, rows: Task[]) {
  feedback.value = `第 ${from + 1} 项移至第 ${to + 1} 项；当前顺序：${rows.map((row) => row.name).join('、')}`
}
function begin(_key: ProKey, record: Task) {
  feedback.value = `正在编辑：${record.name}`
}
function end(_key: ProKey, record: Task) {
  feedback.value = `编辑结束：${record.name}`
}
</script>

<template>
  <div class="enhanced-demo" data-demo="table-enhancements">
    <section data-demo-drag-table>
      <h3>拖动排序</h3>
      <p>拖动行首手柄，或聚焦手柄后按 ↑ / ↓。排序结果保存在当前页面。</p>
      <DragSortTable
        v-model:data-source="dragRows"
        row-key="id"
        :columns="columns"
        :search="false"
        :options="false"
        :pagination="false"
        :tool-bar-render="false"
        @drag-sort-end="dragEnd"
      />
    </section>
    <section data-demo-row-table>
      <h3>行编辑</h3>
      <p>双击一行进入编辑，焦点离开当前行后保存；按钮也可启动、保存和取消。</p>
      <Space class="actions">
        <Button data-demo-row-start @click="rowAction?.startEditable(1)">编辑第一行</Button>
        <Button data-demo-row-save @click="rowAction?.saveEditable(1)">保存第一行</Button>
        <Button data-demo-row-cancel @click="rowAction?.cancelEditable(1)">取消编辑</Button>
      </Space>
      <RowEditorTable
        ref="rowAction"
        v-model:data-source="rowRows"
        row-key="id"
        :columns="columns"
        :editable="editable"
        :search="false"
        :options="false"
        :pagination="false"
        :tool-bar-render="false"
        :on-row-edit-start="begin"
        :on-row-edit-end="end"
      />
    </section>
    <section data-demo-cell-table>
      <h3>单元格编辑</h3>
      <p>双击名称或优先级，只编辑当前单元格；切换单元格时先保存并校验。</p>
      <Space class="actions">
        <Button data-demo-cell-start @click="cellAction?.startEditable(1)">编辑首个单元格</Button>
        <Button data-demo-cell-save @click="cellAction?.saveEditable(1)">保存第一行</Button>
        <Button data-demo-cell-cancel @click="cellAction?.cancelEditable(1)">取消编辑</Button>
      </Space>
      <CellEditorTable
        ref="cellAction"
        v-model:data-source="cellRows"
        row-key="id"
        :columns="columns"
        :editable="editable"
        :search="false"
        :options="false"
        :pagination="false"
        :tool-bar-render="false"
        :on-row-edit-start="begin"
        :on-row-edit-end="end"
      />
    </section>
    <p data-demo-enhanced-state aria-live="polite">{{ feedback }}</p>
  </div>
</template>

Minimal usage ​

vue
<script setup lang="ts">
import { ref } from 'vue'
import { DragSortTable, type ProColumns } from '@bubblesjs/antdv-next-pro'

type Task = { id: number; title: string }
const rows = ref<Task[]>([
  { id: 1, title: 'Plan work' },
  { id: 2, title: 'Verify changes' },
])
const columns: ProColumns<Task>[] = [{ title: 'Task', dataIndex: 'title' }]
</script>

<template>
  <DragSortTable
    v-model:dataSource="rows"
    row-key="id"
    :columns="columns"
    :search="false"
    :pagination="false"
  />
</template>

DragSortTable ​

Uses ProTable record type T and request parameter type P. Handles support dragging and keyboard Up/Down; controlled parents must accept the reordered array.

Properties ​

PropertyTypeDefaultDescription and source
dragSortKeystring__dragSortHandle column key or dataIndex; inserts a leading column if missing.
dragSortHandlerRender(record: T, index: number) => VNodeChildDefault drag iconCustom handle contents; the outer handle retains drag and keyboard handling.
onDragSortEnd(beforeIndex: number, afterIndex: number, rows: T[]) => void | Promise<void>—Reorder callback; the same listener channel as drag-sort-end.
onDataSourceChange(rows: T[]) => void—Order-change callback; the same listener channel as data-source-change.
dataSourceT[]—Controlled rows; accept the reordered full array with v-model:data-source.
defaultDataSourceT[][]Initial uncontrolled rows.
Remaining propertiesProTableProps<T, P>ProTable defaultsInherits all ProTable properties and columns; see Table API for native options.

Events ​

Event / callbackArgumentsDescription and source
update:data-sourcerows: T[]Reordered rows for two-way binding.
drag-sort-endbeforeIndex: number, afterIndex: number, rows: T[]Same listener as onDragSortEnd; indexes refer to current full-source positions.
data-source-changerows: T[]Same listener as onDataSourceChange; the reordered full array.
Other ProTable eventsUnchangedForwards ProTable events.

Event indexes are positions in the current source, not permanent database ranks after pagination. Persist changes in the callback; returning a Promise does not enable rollback. The default handle class ant-pro-table-drag-icon follows global/component prefixes.

RowEditorTable ​

Double-click a row to edit; focus leaving the row triggers validation and save after 150ms. Moving focus within the row does not save. False from editable.onSave or failed validation retains editing.

Properties ​

PropertyTypeDefaultDescription and source
dataSourceT[]—Alias for value; supports v-model:data-source. Value takes precedence.
defaultDataSourceT[][]Alias for defaultValue; defaultValue takes precedence.
onRowEditStart(key: ProKey, record: T) => void—Called when editing starts; also accepted as @row-edit-start.
onRowEditEnd(key: ProKey, record: T) => void—Called after successful save, cancellation or key removal; also @row-edit-end.
editablefalse | EditableConfig<T>{ type: 'single' }All options, including onSave/onCancel/formProps/formRef, follow editable.
recordCreatorPropsfalse | RecordCreatorProps<T>falseCreator button is hidden by default; explicitly enable record creation.
onRowTableProps<T>['onRow']—Native Table row bindings; original handlers run first and may preventDefault to block activation.
Remaining propertiesEditableProTableProps<T, P>InheritedInherits EditableProTable properties, including value/defaultValue/editableKeys/maxLength/formItemProps; search/pagination remain disabled.

Events and callbacks ​

Event / callbackArgumentsDescription and source
update:data-sourcerows: T[]Row-value changes for the dataSource alias.
update:editable-keyskeys: ProKey[]Controlled editing-key updates.
row-edit-start / onRowEditStartkey: ProKey, record: TEntered editing automatically or through a ref method.
row-edit-end / onRowEditEndkey: ProKey, record: TSuccessful save, cancellation or editing-key removal.
Other EditableProTable eventsUnchangedSee EditableProTable events.

onRowEditStart and @row-edit-start (and the corresponding end forms) are the same Vue listener; choose one syntax.

CellEditorTable ​

Double-click an editable cell to show its input; leaving the cell saves after 150ms. Switching first saves the current cell, and failed validation blocks switching.

Properties ​

PropertyTypeDefaultDescription and source
All propertiesCellEditorTableProps<T, P> = RowEditorTableProps<T, P>RowEditorTable defaultsAdds no properties; see RowEditorTable properties and EditableProTable properties.
columns[].onCellTableColumnType<T>['onCell']—Native Column bindings; the original double-click handler runs first and may preventDefault to block activation.

Events and callbacks ​

Event / callbackArgumentsDescription and source
update:data-sourcerows: T[]Row-value changes for the dataSource alias.
update:editable-keyskeys: ProKey[]Controlled editing-key updates.
row-edit-start / onRowEditStartkey: ProKey, record: TEntered editing automatically or through a ref method.
row-edit-end / onRowEditEndkey: ProKey, record: TSuccessful save, cancellation or editing-key removal.
Other EditableProTable eventsUnchangedSee EditableProTable events.

readonly, editable=false, and valueType="option" columns cannot be edited. Ref method startEditable(key) selects the first editable field in the row.

Slots ​

ComponentSlots and arguments
DragSortTableForwards all ProTable slots, including toolbar-actions, dynamic headers/cells, before-table/after-table and native slots; adds no slots.
RowEditorTable / CellEditorTableForwards all EditableProTable slots, including creator-button and all ProTable slots; adds no slots.

Instance ​

Component / methodReturnBehavior and source
DragSortTableProTableInstance<T>Inherits all ProTable methods; adds no methods.
RowEditorTable / CellEditorTableProTableInstance<T>See all ProTable methods and arguments; the three methods below also coordinate editing notifications.
startEditable(key: ProKey)booleanStarts row/first-cell editing and calls onRowEditStart.
saveEditable(key: ProKey)Promise<boolean>Validates and saves; success calls onRowEditEnd, failure retains editing.
cancelEditable(key: ProKey)voidCancels, restores and calls onRowEditEnd.

Configuration and styling ​

prefixCls/classes/styles and native theme follow ProTable; see ProConfigProvider for extension tokens, locale and RTL. Full signatures and native property links for render/formItemRender/fieldProps/formItemProps are listed in ProColumns.

The 150ms delay buffers focus changes. Return the real network Promise from editable.onSave. Cross-page sorting and server ranks remain application responsibilities.
