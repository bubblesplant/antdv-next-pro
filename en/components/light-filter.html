Components/LightFilter

LightFilter ​

LightFilter is a standalone form that presents fields as filter labels. Click a label to open a popover and confirm to submit. ProTable uses the same component when search.filterType='light'.

Import ​

ts
import { LightFilter, ProFormText, ProFormSelect } from '@bubblesjs/antdv-next-pro'
import '@bubblesjs/antdv-next-pro/style.css'

You can also register <LightFilter> globally with app.use(AntdvNextPro). See Getting started.

Filter labels and secondary fields ​

Compose ProForm fields in the default slot. Ordinary fields have their own filter labels, while fields with secondary appear under More. Bind values with v-model and handle searches with :on-finish="search".

View full source
vue
<script setup lang="ts">
import { ref } from 'vue'
import { LightFilter, ProFormSelect, ProFormText } from '@bubblesjs/antdv-next-pro'

const model = ref<Record<string, unknown>>({})
const submitted = ref('')
const count = ref(0)

function search(values: Record<string, unknown>) {
  submitted.value = JSON.stringify(values, null, 2)
  count.value++
  return true
}
</script>

<template>
  <div>
    <LightFilter v-model="model" :on-finish="search">
      <ProFormText
        name="keyword"
        label="项目名称"
        :field-props="{ placeholder: '输入后点击确认' }"
      />
      <ProFormSelect
        name="status"
        label="项目状态"
        :options="[
          { label: '进行中', value: 'active' },
          { label: '已完成', value: 'done' },
        ]"
      />
      <ProFormText
        name="owner"
        label="负责人"
        secondary
        :field-props="{ placeholder: '在更多筛选中填写' }"
      />
    </LightFilter>
    <div class="filter-result" aria-live="polite">
      <p>已查询 {{ count }} 次 · 确认应用条件，关闭弹层取消本次编辑，清除后重新查询。</p>
      <span>{{ submitted ? '最近一次查询参数' : '当前表单值' }}</span>
      <pre>{{ submitted || JSON.stringify(model, null, 2) }}</pre>
    </div>
  </div>
</template>

<style scoped>
.filter-result {
  margin-top: 20px;
  padding: 16px;
  border: 1px solid #e8ecf1;
  border-radius: 6px;
  background: #fafbfc;

</style>

Confirmation validates and submits. Closing a popover without confirmation restores its opening snapshot. Clearing removes the current field or group's values and submits again. Editing updates v-model; searches run on confirmation or clearing.

Collect every field ​

Set collapse=true to collect all fields in one popover, and customize its label with collapseLabel. Call reset() through the component ref to restore all initial values.

View full source
vue
<script setup lang="ts">
import { ref } from 'vue'
import { Button, Space } from 'antdv-next'
import {
  LightFilter,
  ProFormSelect,
  ProFormText,
  type ProFormInstance,
} from '@bubblesjs/antdv-next-pro'

const form = ref<ProFormInstance>()
const model = ref<Record<string, unknown>>({})
const submitted = ref('')

function search(values: Record<string, unknown>) {
  submitted.value = JSON.stringify(values, null, 2)
  return true
}
</script>

<template>
  <div>
    <Space align="start" wrap>
      <LightFilter
        ref="form"
        v-model="model"
        collapse
        collapse-label="筛选项目"
        placement="bottomLeft"
        :on-finish="search"
        @reset="submitted = ''"
      >
        <ProFormText
          name="keyword"
          label="项目名称"
          :field-props="{ placeholder: '请输入项目名称' }"
        />
        <ProFormSelect
          name="status"
          label="项目状态"
          :options="[
            { label: '进行中', value: 'active' },
            { label: '已完成', value: 'done' },
          ]"
        />
        <ProFormText name="owner" label="负责人" />
      </LightFilter>
      <Button @click="form?.reset()">重置全部条件</Button>
    </Space>
    <pre class="filter-result" aria-live="polite">{{
      submitted || JSON.stringify(model, null, 2)
    }}</pre>
  </div>
</template>

<style scoped>
.filter-result {
  margin-top: 20px;
  overflow: auto;
  padding: 16px;
  border: 1px solid #e8ecf1;
  border-radius: 6px;
  background: #fafbfc;
  color: #334155;
  font-size: 12px;
}
</style>

Schema fields ​

As with QueryFilter, you can pass SchemaForm columns instead of composing field children:

vue
<script setup lang="ts">
import { ref } from 'vue'
import { LightFilter, type SchemaFormColumn } from '@bubblesjs/antdv-next-pro'

const filters = ref<Record<string, unknown>>({})
const columns: SchemaFormColumn[] = [
  { title: 'Project', dataIndex: 'keyword' },
  {
    title: 'Status',
    dataIndex: 'status',
    valueType: 'select',
    valueEnum: { active: 'Active', done: 'Done' },
  },
]

function search(values: Record<string, unknown>) {
  console.log(values)
  return true
}
</script>

<template>
  <LightFilter v-model="filters" :columns="columns" :on-finish="search" />
</template>

API ​

The component also supports the shared ProForm options, including initialValues, request, params, validation, value formatting, and URL synchronization.

PropertyTypeDefault / description
modelValue / v-modelPartial<T>Current filter values
columnsSchemaFormColumn<T>[]Optional schema fields
onFinish(values) => boolean | void | Promise<boolean | void>Search callback on confirmation or clearing; bind with :on-finish
collapsebooleanfalse; collect all fields in one popover
collapseLabelVNodeChildLocalized More label
placementPopoverProps['placement']'bottomLeft'
footerRenderfalse | ({ confirm, clear }, doms) => VNodeChildCustomize popover actions; false hides the footer

Set a field's secondary property to place it under More. With collapse=true, all fields share one popover. This grouping option is separate from QueryFilter's v-model:collapsed state.

EventDescription
update:modelValue / changeValues changed, including unconfirmed edits
submitObserve submission; use onFinish to await business results
resetRestore the initialization snapshot through the instance
error / requestErrorSubmission error / initialization request error

The default slot composes fields. The component ref exposes getFieldsValue(), setFieldsValue(), validate(), submit(), and reset(). Use ProFormInstance for composed fields or SchemaFormInstance<T> for schema fields. See ProForm instance methods.
