✧✧

ProTable，把表格准备好

搜索、分页、排序、筛选与远程请求，收束进一张表格，让数据流清晰可控。

↗

EditableProTable，随手编辑

新建行、多行编辑、字段校验与异步保存。通过受控 value，管理整张表格的数据。

↗

SchemaForm，让字段成形

从同一套列模型出发，生成普通、查询、弹窗、抽屉与步骤表单，让配置自然复用。

↗

一套 columns，贯穿工作流

在一处描述字段，让查询、展示、编辑与提交连贯起来，把时间留给真正的业务。

↗

熟悉的 Vue，顺手的交互

基于 Vue 3 与 Antdv Next，用组件 ref、事件、插槽和 v-model，表达你的界面。

↗

从 React 到 Vue，迁移有据

对照兼容矩阵，了解主要 Props、请求契约与 Vue 写法，为已有工作流找到对应方式。
