## 文档与公开边界

已同步中英文 ProCard 文档，覆盖响应式分栏、父 colStyle、Group/Divider、tabs/历史 TabPane、tooltip 对象、七部位、Vue 事件/插槽及主题入口。兼容说明补充 Row/Cell 双数据模型和 List grid Card 动作部位；新增族的完整双语 API/演示由 foundation/forms 协作完成。Descriptions 的 Vue 特殊 `key` 从 VNode key 读取，不将其声明为普通 prop，并保留传给 render/formItemRender 的 schema key。

泛型声明保留 RowEditorTable/CellEditorTable/DragSortTable/ProList/ProDescriptions 的记录类型、回调及 exposed ref；ProList 明确重声明 `request?: ProRequest<T,P>`，避免发布 DTS 在 Omit 继承后丢失记录约束。五个消费者负例全部保留。

原生 ConfigProvider 的 locale/prefixCls/direction/theme 动态继承，原生 Card token 仍由原生 Card 消费，Pro 扩展 token 由 ProConfigProvider 入口消费。没有将 `theme.components.Result` 宣传为 Pro 的独立 token。class/slot/ref/v-model 按 Vue 合理适配保留。

没有验证所有浏览器/操作系统、全部原生组件属性、所有时区或与 React 内部 DOM/CSS 哈希逐字相等。默认状态、公开类与必要结构按固定提交对照；官网部署提交无法证明时不作相同版本断言。没有提交、发布或部署；用户原有修改未回滚。本域没有新建需要安装依赖的大型临时项目，上游审计 checkout 的策略拒绝清理由主控在最终报告记录。
